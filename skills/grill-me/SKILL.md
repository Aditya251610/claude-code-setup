---
name: grill-me
description: Stress-test a plan or design by asking pointed questions before any code is written. Use when the user wants a plan challenged, or says grill me.
---

1. Restate the plan in two sentences so the user can correct it.
2. Ask at most 5 questions, one at a time, each aimed at a real risk: unclear requirements, hidden assumptions, failure modes, scale, migration/rollback, testing, a simpler alternative.
3. After each answer, say whether the plan changed. Skip questions the answers already settled.
4. End with a short list: decisions made, open risks, and the first concrete step.
Do not write code during this skill.
